# DATABASE - medicare-fraud-detector

## Overview
The database is a single SQLite file (`data/claims.db`) containing one table `cms_claims` that mirrors the CMS Medicare Physician & Other Practitioners by Provider and Service PUF.

## Table: cms_claims
- **clm_id**: TEXT PRIMARY KEY (e.g., CLM0000001)
- **rndrng_npi**: TEXT NOT NULL (10-digit National Provider Identifier)
- **rndrng_prvdr_last_org_name**: TEXT
- **rndrng_prvdr_first_name**: TEXT
- **rndrng_prvdr_crdntls**: TEXT (e.g., MD, DO, NP, PA)
- **rndrng_prvdr_type**: TEXT (e.g., Internal Medicine, Cardiology)
- **rndrng_prvdr_state_abrvtn**: TEXT (US state code, blank if foreign)
- **rndrng_prvdr_cntry**: TEXT NOT NULL (US or ISO country code)
- **hcpcs_cd**: TEXT NOT NULL (HCPCS procedure code)
- **hcpcs_desc**: TEXT
- **place_of_srvc**: TEXT (O=office, F=facility)
- **clm_from_dt**: DATE NOT NULL (claim start date)
- **clm_thru_dt**: DATE NOT NULL (claim end date)
- **avg_sbmtd_chrg**: REAL (average submitted charge)
- **avg_mdcr_alowd_amt**: REAL (average Medicare allowed amount)
- **avg_mdcr_pymt_amt**: REAL (average Medicare payment amount)

## Indexes
- `idx_npi` on `rndrng_npi`
- `idx_cntry` on `rndrng_prvdr_cntry`
- `idx_dates` on (`clm_from_dt`, `clm_thru_dt`)

## Data Source
- The table is populated from a CSV file (`data/claims.csv`).
- The CSV follows the exact CMS PUF structure and column names.
- A synthetic dataset is generated by `data/generate.py` for development and testing.
- To use real CMS data, replace `data/claims.csv` with the downloaded CSV and re-import.

## Schema Management
- The schema is defined in `queries/01_schema.sql`.
- The script includes comments on how to load the real CMS dataset.
- Indexes are created to support the fraud detection queries.
